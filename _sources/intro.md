# Grokking Machine Learning

This Jupyter Book is organized directly from the supplied notebook collection for *Grokking Machine Learning*. The notebooks, their Markdown explanations, code, comments, displayed outputs, and bundled data files are retained as the source material.

The supplied archive contains notebook material for Chapters 3–6 and 8–13. Chapters 1, 2, and 7 are listed in the source README but no notebooks for those chapters are present in the archive; they are therefore not recreated here.
